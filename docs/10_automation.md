# 10 人の工程を減らす自動化

## 原則

1. 機械で確かめられることは機械が処理する
2. 人が見るのは例外だけにする
3. 記録の判断は1件ずつでなく、文献単位にまとめる
4. 自動公開はAIではなく、説明できる規則で行う。AIの出力だけを根拠に公開しない
5. 誤りは公開後でも戻せるようにする。すべての変更を監査ログと版に残す

すべての自動公開は機能フラグで止められる。初期値は偽とし、閲覧サイトの公開後に1つずつ有効にする。

## 自動で処理するもの

| 処理 | 条件 | フラグ |
|---|---|---|
| 書誌の公開 | DOI から取得でき、重複がない | `auto_publish_doi_references` |
| 目録の公開 | 収集元が J-STAGE、NDLサーチ、CiNii で、重複がない | `auto_publish_catalog_harvest` |
| リンクの公開 | `https` で `trusted_domains` に一致し、応答が200 | `auto_publish_trusted_links` |
| リンク切れの処理 | 2回連続で失敗 | 常時 |
| 記録の公開 | 下の全条件を満たす | `auto_publish_trusted_records` |
| PDFの公開 | 検査が正常で、権利の申告が `09_literature_repository.md` の規則を満たす | `auto_publish_declared_scans` |
| スパムの隔離 | 回数制限超過、AI判定 | `ai_triage` |
| 公開データの更新 | 毎週。停止条件に当たらない | `weekly_auto_release` |

## 記録の自動公開の条件

次をすべて満たす場合のみ公開する。

- 投稿者の `trust_level` が2
- 文献が公開済み
- 学名が現行学名に対応している
- 分類群の状態が `accepted`
- `sensitivity` が0
- 県の証拠区分がすでに `original` か `citation` である
- 同じ文献で重複がない

**必ず人へ回すもの**

- 県初記録、日本初記録の候補
- 機微種
- 学名が未対応の記録
- 既存の記録と矛盾する提案
- 誤同定の指摘と学名の変更
- 規則を満たさない権利の申告

自動公開した記録の5%を無作為に抽出し、`post_review_sampled = true` として公開後の確認に回す。

## 投稿者の信頼度

| 昇格 | 条件 |
|---|---|
| 0 → 1 | 承認20件、却下なし。自動で昇格 |
| 1 → 2 | 承認100件、却下率2%未満。審査者が1回承認 |

抜き取りで誤りが見つかると1段階下げる。

## 人の作業をまとめる仕組み

| 仕組み | 効果 |
|---|---|
| 文献単位の一括承認 | 1本の論文の記録を1回で処理する |
| 権利の申告 | 登録者が根拠を示すので、審査は確認だけで済む |
| 既定の絞り込み | 受信箱には人の判断が必要なものだけを表示する |
| 通知のまとめ | 緊急以外は毎朝1通 |
| 担当の自動割当 | 科と地域で担当者を決める |
| AIの下処理 | 根拠の確認と差分案を先に用意する |

## 週次の自動公開

`publish-data.yml` は毎週実行し、次の場合は公開せずオーナーへ通知する。

- 公開記録が前の版より1%以上減る
- 公開文献が前の版より1%以上減る
- 種の数が変わる（学名変更の承認があった場合を除く）
- `verify.ts` が失敗する

問題があれば管理画面から前の版へ戻す。

## 運用の自動化

| 作業 | 方法 |
|---|---|
| 開発用依存の更新 | パッチ版のみ CI 通過で自動マージ |
| Zenodo への登録 | 四半期ごとに `ZENODO_TOKEN` で自動登録 |
| バックアップの確認 | 毎月自動で復元を試す |
| リンク切れの確認 | 毎月自動 |
| 投稿者への結果通知 | 自動 |

## 人に残る作業

| 人 | 作業 | 目安 |
|---|---|---|
| 投稿者 | DOIの入力、または目録にない文献の入力、スキャンの提供 | 文献ごと |
| 審査者 | 新記録候補などの例外の確認、文献単位の承認 | 毎朝の通知を見る |
| 編集者 | 学名変更の承認 | 発生時 |
| 管理者 | 公開停止の判断 | 発生時 |
| オーナー | 週1分の確認、月5分の依存更新、年30分の見直し | 上記 |

## 測定

管理画面に次を表示し、人の負担を確認する。

- 全処理のうち自動で完了した割合
- 審査の待ち件数と平均待ち時間
- 審査者ごとの週あたり処理数
- 自動公開の抜き取りで見つかった誤りの率

誤りの率が2%を超えた場合は、該当のフラグを切ってオーナーへ通知する。
