# 14 広域分布

文献や図鑑には「本州、四国、九州」のように県を特定しない分布がある。これを県の記録と混ぜずに扱う。

テーブルは `docs/14_broad_ranges_schema.sql`、地域は `seed/broad_regions.csv` に定義する。

## 基本の考え方

1. 広域の記録は1件の主張として保存する。県の数へ展開しない
2. 文献の表記は `locality_verbatim` にそのまま残す
3. 県の記録があれば、県の記録を優先して表示する
4. 広域の記録は県の記録数と種数に数えない

## 地域

`regions.region_type = 'broad'` とする。コードは `BR01` から始める。

| コード | 名称 | 含む都府県 |
|---|---|---|
| `BR01` | 本州 | 青森県から山口県までの34都府県 |
| `BR02` | 四国 | 徳島県、香川県、愛媛県、高知県 |
| `BR03` | 九州 | 福岡県から鹿児島県までの7県 |

- `region_members` は都道府県だけを持つ。佐渡や隠岐などの島は広域に含めない
- 島のページに広域の記録を反映しない。島は島の記録がある場合だけ扱う
- 南西諸島など県の一部にまたがる範囲は追加しない。県全体を塗ると誤解を生むためである。必要になったら `docs/questions.md` で確認する
- 地域の追加は編集者が行う

## 記録の入力

- 「本州、四国、九州」は地域ごとに3件の記録とし、同じ文献とページを指す
- 広域の記録は `island_id`, `lat`, `lon` を持てない。DBで拒否する
- 記録の区分は県の記録と同じく `original`, `citation` などを使う
- 広域の記録は自動公開の対象にしない
- AI文献抽出では、広域の表記を県へ推測で展開しない

## 分布の判定

種と都道府県の組み合わせごとに、次の順で状態を決める。

| 順 | 条件 | 状態 |
|---|---|---|
| 1 | その県の公開記録、標本、写真がある | 既存の証拠区分 |
| 2 | その県を含む広域の公開記録がある | `broad` |
| 3 | どちらもない | `none` |

誤同定（`accuracy = 'misidentification'`）の広域記録は判定に使わない。

## 公開データ

- `region_status` の値に `broad` を加える。県ごとの判定は公開データの生成時に作る
- 記録の出力は広域のまま1件とする。CSVに `region_level` 列（`prefecture`, `island`, `broad`, `other`）を加える
- 県のCSVに広域の記録を入れない
- `taxa.sensitivity = 2` の種は、県と同じく地域の有無だけを出す

## 画面

| 場所 | 表示 |
|---|---|
| 分布図 | `broad` の県を薄い色で塗る。凡例は「広域の記録のみ」 |
| 種ページの表 | 文献ごとに「本州、四国、九州」のように1行へまとめる |
| 県ページの種リスト | 既定では県の記録がある種だけを出し、「広域の記録のみの種」を別に切り替えられる |
| 発見候補 | `broad` の種を「県の記録を探している種」に含める |
| 全国の集計 | 県の記録だけを数える |

## 受け入れの数値

- 本州34、四国4、九州7の都府県を持つ
- 地域の総数は141になる（既存138 + 広域3）
