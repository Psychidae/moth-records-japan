日本産蛾類DB 見取り図

文献の根拠つきで、蛾の記録を都道府県ごとに見渡せるデータベースの全体設計です。図の中の W1〜W6 は作業場（ワークベンチ）の番号で、仕様書 docs/05_portal_admin.md と対応しています。

全体の構造

データが公開されるまで

文献リポジトリ

公開済みのPDFにはリンクで到達できるようにします。たとえば蛾類通信 No.1〜309 と TINEA 第1巻〜第27巻2号は学会サイトへのリンクで読めます。それでも取りこぼしている文献は、著者本人や、著作権の保護期間の満了に気づいた人が登録し、本サイトが保持します。学会が頒布中の号は入手案内を出し、登録は受け付けません。

人の工程

機械で確かめられることは機械が処理し、人は例外だけを判断します。自動公開はAIの判断ではなく、説明できる規則で行います。

処理自動で進む条件必ず人が見るもの
書誌DOIで確定、または収集元が信頼でき重複がない題名だけ一致する重複候補
リンク信頼ドメインで応答が正常それ以外のドメイン
記録信頼済み投稿者で、既に記録のある県の通常の記録。5%を抜き取り確認県初記録、日本初記録、希少種、学名未対応
PDF登録検査が正常で、権利の申告が規則を満たす規則に合わない申告、公開停止の判断
公開毎週自動。記録が1%以上減るときは停止停止の通知

記録の審査は文献単位の一括承認を基本にします。審査の待ち件数と自動処理の割合は管理画面で確認できます。

使うツールと運用耐性

判断基準は、1人で運用できること、やめても移せること、資金が止まっても公開サイトを残せることの3点です。料金と上限は2026年11月時点の確認結果です。

役割採用確認した上限撤退方法
公開配信Cloudflare Workers Static Assets静的要求は無料で無制限、Free 2万ファイル静的ファイルを他社へ移す
サイト生成Astro（静的出力のみ）15,628ページを5.5秒で生成（簡略な雛形で実測）出力はHTML
投稿、管理Vite + React静的SPAとして配信標準的なReact
DB、認証Supabase 東京Pro $25/月〜、8GB、10万MAUpg_dump で移行
軽い処理Edge Functions200万回/月、CPU 2秒他の実行環境へ移す
定期処理GitHub Actions公開リポジトリは無料他のCIへ移す
メールResend無料 100通/日SMTP設定の変更
保護Turnstile、Cloudflare AccessAccessは50人まで無料。Turnstileの無料枠は未確認外してもMFAとRLSは残る
バックアップR2 + age10GBまで無料、転送無料S3互換の別サービス

運用で注意する点

公開リポジトリの定期処理は、60日間活動がないと自動で止まります。週次の状態更新で活動を保ち、止まった場合は外部の停止検知からメールが届く設計です。バックアップのロックはCloudflareの管理者なら解除できるため、公開データは GitHub と Zenodo にも置いて提供元を分散します。

頻度やること目安
