# 04 公開サイト（閲覧ワークベンチ）

`apps/public`。Astro の静的生成。ログインなし、DB接続なし、外部スクリプトなし。写真、コメント、順位は読み取りAPIから取得し、失敗しても静的な内容を表示する。`15_community.md`

## 共通

見た目と操作性は `13_design.md` に従う。

- スマートフォンを先に設計する。幅320pxで横スクロールを出さない
- 全ページのヘッダーに検索窓を置く
- ナビ: 種をさがす、地域から見る、文献、タイプ産地、寄主植物、データ、参加する
- 全データページの末尾に「修正を提案」リンクを置く。リンク先は `https://<SUBMIT_DOMAIN>/suggest?target=<種別>:<コード>`
- 全データページの末尾に引用文（版番号、閲覧日、コピーボタン）を置く
- 解析は Cloudflare Web Analytics のみ。Google Analytics と広告タグは入れない
- 種、地域、文献ページに `schema.org` の構造化データを出力する
- 絞り込み条件はURLのクエリに保持する。`robots.txt` で絞り込みURLを検索対象から外す

## トップ

検索窓、収録数（種、記録、文献、都道府県）、全国地図、最近追加された文献、最近の学名変更を表示する。

## 検索

- `names.json` をブラウザで検索する
- 対象: 学名、和名、別名、異名、文献上の表記、属名、科名
- 異名で一致した場合は「現在の学名は〜」と表示する
- ひらがな、カタカナ、全角半角の差を正規化する

## 種ページ

上から次の順で表示する。

1. 和名、学名、命名者、分類階層、List-MJでの扱い、別名
2. 分布図。証拠の層（文献、標本、iNaturalist、投稿写真）を切り替える
3. 県別の表。証拠区分、最初の文献、最新の文献、記録数
4. 発見候補がある県の案内
5. 月別の出現グラフ（日付つきの記録のみ）
6. 写真。本サイトの投稿写真、iNaturalist の順に、成虫、幼虫などに分けて撮影者とライセンスを表示。「別の種では？」の提案を置く。ない場合は「写真募集」と投稿への案内。`12_photos.md`
7. タイプ情報と学名の沿革
8. 文献一覧。原記載、日本初記録、県初記録、その他に分類
9. 寄主植物。関連ごとに根拠の文献を表示
10. 類似種
11. 外部リンクと関連する議論（図鑑、掲示板など）
12. 修正の提案と引用文

機微種は「保護のため詳細な産地を表示していません」と表示する。

## 全国地図と地域ページ

**全国地図**

- 自前のSVG部品で描き、都道府県の実際の形を塗り分ける。元データは Natural Earth の `ne_10m_admin_1_states_provinces`（パブリックドメイン）とし、`mapshaper` で簡略化してビルド時にSVGへ変換する
- 南西諸島は左上の枠に入れる。小笠原諸島と南千島は地図の下に別枠の地域として置く
- 地図ライブラリと背景地図タイルは使わない。島は円で示す
- 表示項目を切り替える: 種数、記録数、文献数
- 科、年代、記録区分、正確性で絞り込む

**県、島ページ**

- 種リスト（証拠区分で絞り込み、CSV出力）
- 主な文献、年代別の記録数、月別の種数
- 発見候補: 標本や写真はあるが文献記録のない種
- 未記録候補: 隣接県で記録があるがこの県にない種。隣接関係は `seed/adjacency.csv`

## 文献ページ

書誌、DOI、読める場所の一覧（外部リンク、当サイトのスキャンと該当ページ）、この文献が扱った名称の一覧、記録の一覧を表示する。本体がない場合は「スキャン募集中」と投稿への案内を出す。一覧ページでは著者、年、誌名、リンクの有無で絞り込む。

## 記録の表示

文献上の学名を必ず併記する。次は表示形式の架空の例である。

```text
Issikiomartyria nudata（文献上の表記: Neomicropteryx nudata）
原記録 / 通常 / 北海道 札幌市 / 2001年7月 / 山田 2002: 12
```

記録区分の表示名: `original` 原記録、`citation` 引用、`unconfirmed` 未確認、`unknown` 不明、`board` 掲示板情報。正確性の表示名: 通常、要確認、誤同定。

## データページ

CSV: 記録、種リスト、文献、著者、県別チェックリスト。Darwin Core 形式の記録と分類群。ログイン不要で配布する。ライセンス、版、SHA-256 を併記する。出典として List-MJ、iNaturalist、GBIF の利用条件と引用DOIを明示する。
