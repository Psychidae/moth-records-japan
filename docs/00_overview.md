# 00 全体像

## 目的

日本国内の蛾類の記録を、文献の根拠つきで都道府県ごとに俯瞰できる公開データベースを作る。

- 分類基盤は List-MJ（CC0 1.0）。
- 誰でも文献情報と記録を投稿でき、審査後に公開する。
- 訪問者は間違いや分類の変更を提案でき、AIが下処理して管理者へ通知する。
- 既存の図鑑、掲示板、iNaturalist、GBIF とはリンクと集計でつなぐ。写真の投稿と交流は `15_community.md` のとおり本サイトでも行う。
- 閲覧は匿名でできる。交流、投稿、マイ図鑑、大会はアカウントを求める。
- 文献の本体は、外部で公開済みならリンクし、目録しかないものはスキャンを受け入れて保持する。

## 設計の中心原則

1. **記録の単位は「文献が述べた1件の主張」**。文献、ページ、文献上の学名、原文の地名を必ず持つ。
2. **文献上の学名は書き換えない**。現行学名との対応は `records.taxon_id` で別に持つ。学名が変わっても元の記録は変わらない。
3. **証拠の種類を混ぜない**。文献、標本、写真を区別して表示する。
4. **疑わしい記録は消さず注釈する**。`accuracy` で区別し、利用者が絞り込める。
5. **閲覧と投稿を分離する**。公開サイトは静的ファイルのみ。データベースへ接続しない。
6. **AIは提案だけを行う**。データの変更は必ず人が承認する。
7. **運用はオーナーの作業が最小になるよう自動化する**。オーナーは運用の初心者である。
8. **人が判断するのは例外だけにする**。記録の判断は1件ごとではなく、文献単位にまとめる。

## 確定事項

| 項目 | 決定 |
|---|---|
| 対象 | 蛾類のみ。List-MJ の掲載範囲 |
| 地理単位 | 都道府県と主要島嶼。南千島は別区分。県を特定しない本州、四国、九州は広域の記録として分ける |
| 構成 | 公開サイト、投稿サイト、管理サイトの分離 |
| 公開順序 | 閲覧サイトを先に公開。投稿機能は安全確認後に開く |
| データライセンス | 記録データ CC BY 4.0、List-MJ由来の分類基盤 CC0 1.0 |
| 権限 | 利用者、キュレーター、運営者、オーナーの4段階。審査者と編集者はキュレーターへ統合する。`15_community.md` |
| 投稿の反映 | 先に「未確認」として公開し、キュレーターが後から直す。分布図の証拠区分は確認後に変える |
| 写真の公開 | 公開を基本とし、投稿者は写真ごとに非公開を選べる |
| 運営費 | Cloudflare の独自ドメインと無料枠で、年1,600円程度で運営する。増えた費用は運営費の支援から支払う |
| 観察写真 | 誰でも投稿でき、種へ登録、移動できる。希望者は iNaturalist へ同時に投稿する。`12_photos.md` |
| 標本画像 | 標本、交尾器、タイプ標本の画像は将来審査制で受付（T42） |
| 文献の本体 | 公開済みPDFはリンクで到達できるようにする。取りこぼしは、著者本人や保護期間の満了に気づいた人が1件ずつ登録し、本サイトが保持する |
| AI | Claude API。既定モデル `claude-opus-5-5`。変更は人が承認 |
| 防御の水準 | ランサムウェア、改ざん、マルウェア混入、一般的な攻撃を防ぐ。有償の外部診断は行わない |
