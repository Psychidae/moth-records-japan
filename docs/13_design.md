# 13 デザインと使いやすさ

見た目と操作性の基準を定める。公開、投稿、管理の3サイトで共通に使う。

## 方針

1. **標本箱の台紙とラベル**を手本にする。温かい紙の色、落ち着いたインク、整ったラベルの文字組みで、資料としての信頼感を出す
2. 主役はデータと写真である。装飾で飾らず、余白、文字の階層、罫線で見せる
3. 初めての人が3クリック以内で目的の種にたどり着ける。専門家は検索とURLで直接飛べる
4. 色だけで意味を伝えない。証拠の区分は必ず記号と文字を添える
5. 流行のテンプレートに見せない。角丸の大きなカード、影、グラデーション、絵文字、紫の配色を使わない

他のサイトのロゴ、配色、写真、画面構成を複製しない。

## 色

値は `packages/ui/tokens.css` に CSS 変数として置く。画面のCSSに色の値を直接書かない。

| 変数 | 用途 | ライト | ダーク |
|---|---|---|---|
| `--color-paper` | ページの背景 | `#F6F2E9` | `#17150F` |
| `--color-surface` | 台紙、表、入力欄 | `#FFFDF8` | `#211E17` |
| `--color-raised` | 表の見出し、補助の面 | `#EFE9DC` | `#2C2820` |
| `--color-ink` | 本文 | `#26211B` | `#F0EADD` |
| `--color-muted` | 補足の文字 | `#5C5347` | `#BDB3A2` |
| `--color-line` | 区切りの罫線 | `#D8CFBE` | `#403A2F` |
| `--color-control` | 入力欄の枠 | `#857A69` | `#8F8676` |
| `--color-accent` | リンク、主ボタン | `#245245` | `#8CC7B3` |
| `--color-accent-hover` | 操作中 | `#183A31` | `#B0DDCD` |
| `--color-on-accent` | 主ボタンの文字 | `#FFFDF8` | `#17150F` |
| `--color-focus` | フォーカス枠 | `#9A5B12` | `#E9B56A` |
| `--color-warn` | 注意 | `#8A4B08` | `#E9B56A` |
| `--color-danger` | 誤同定、エラー | `#9B2C22` | `#F0A096` |

ダークモードは端末の設定に従う。切替ボタンは置かない。`Layout.astro` の `color-scheme` を `light dark` にする。

### 証拠の区分

地図、表、バッジで同じ組み合わせを使う。

| 区分 | 表示名 | 記号 | ライト | ダーク |
|---|---|---|---|---|
| `original` | 原記録 | 塗りつぶしの丸 | `#245245` | `#8CC7B3` |
| `citation` | 引用 | 中抜きの丸 | `#3A6793` | `#9CC2E8` |
| `specimen` | 標本 | 塗りつぶしの四角 | `#7A4E8C` | `#CFA8DE` |
| `photo_rg`, `photo_site` | 写真 | 三角 | `#945210` | `#E9B56A` |
| `needs_review` | 要確認 | 破線の丸 | `#626262` | `#C2C2C2` |
| `none` | 記録なし | 空欄と「未記録」の文字 | `--color-muted` | `--color-muted` |

「未記録」は「いない」という意味ではない。地図の凡例に常に明記する。

## 文字

Webフォントで日本語を配信しない。容量が大きいためである。

| 用途 | フォント |
|---|---|
| 本文、操作部品 | `"Hiragino Sans","Hiragino Kaku Gothic ProN","Noto Sans JP","Yu Gothic UI",Meiryo,sans-serif` |
| 見出し | `"Hiragino Mincho ProN","Yu Mincho","Noto Serif JP",serif` |
| 学名、命名者、ラテン文字の見出し | `Source Serif 4`（自己配信） |
| 数値 | 本文と同じ。`font-variant-numeric: tabular-nums` |

- `@fontsource-variable/source-serif-4` の `latin-wght-normal` と `latin-wght-italic` だけを使う。実測で合計約103KBである
- 外部のフォント配信を使わない。`font-display: swap` とする
- 学名は属と種を斜体、命名者と年を立体にする。部品 `ScientificName` を必ず使う

| 階層 | 大きさ | 行間 |
|---|---|---|
| 本文 | 16px。これより小さい本文を作らない | 1.8 |
| 補足 | 14px | 1.7 |
| 小見出し | 18px | 1.6 |
| 中見出し | 22px | 1.5 |
| 大見出し | 28px、幅768px以上で34px | 1.4 |

本文の1行は40全角文字以内とする。

## 形と余白

- 余白は4pxの倍数とする。よく使う値は8, 16, 24, 40, 64px
- 角丸は最大4pxとする。影は使わず、罫線で区切る
- 操作できる部品の大きさは44px四方以上とする
- 動きは150ms以下とし、`prefers-reduced-motion` で止める

## ロゴ

蛾の輪郭を単純な線で描いた自作の SVG を作る。ヘッダー、ファビコン、共有用画像に使う。他の図鑑や学会のロゴに似せない。G4 で名称が決まるまで、文字部分は `site.name` から生成する。

## 使いやすさ

### 全ページ

- ヘッダーの検索窓は全ページで同じ位置に置く
- 幅700px未満では検索窓を常に表示し、ナビは `details` で開閉する。JavaScript がなくても動く
- 現在の場所を示すパンくずを、トップ以外の全ページに置く
- 長い種ページには、セクションへ飛ぶ目次を置く

### トップ

開いて最初の画面に、大きな検索窓と3つの入口を置く。

| 入口 | 行き先 |
|---|---|
| 名前から探す | 検索 |
| 地域から探す | 全国地図 |
| 文献から探す | 文献 |

その下に全国の分布図、記録の件数、更新情報を置く。

### 検索

- 入力中に候補を出す。和名、学名、科を1行で見せる
- 上下キーで候補を選び、Enter で開ける
- 異名で探した場合は「現在の学名」へ案内する
- 0件のときは、表記の違いの例と修正提案への案内を出す

### 種ページ

最初の画面に、和名、学名、分類の位置、分布図の小さな版、証拠の凡例を収める。

- 県別の表は幅600px未満でカード表示に変える
- 長い文献一覧は最初の10件だけ表示し、続きは `details` で開く
- 写真は撮影者とライセンスを必ず見える位置に出す

### 文言

専門用語には短い説明を添える。例: 「原記録（その文献で初めて報告された記録）」

| 場面 | 書くこと |
|---|---|
| データがない | 何がないのかと、次にできること |
| エラー | 何が起きたかと、直し方。コードだけを出さない |
| 成功 | 何が終わったか。コピーでは「コピーしました」と表示する |

### 入力画面

投稿と管理の画面は次を守る。

- 1画面の入力は最小限とし、長い入力は段階に分ける
- エラーは該当の欄のすぐ下に出し、入力内容を消さない
- 必須の欄を明示し、例を添える
- 送信中はボタンを無効にして状態を表示する

### 印刷

種ページと文献ページは印刷用CSSを持つ。ヘッダー、ナビ、ボタンを消し、URLと版番号を残す。

## 部品

`packages/ui` に置き、3サイトで共有する。

`Button`, `Field`, `SearchBox`, `ScientificName`, `EvidenceBadge`, `EvidenceLegend`, `DataTable`, `Notice`, `EmptyState`, `Breadcrumbs`, `Pagination`, `CopyButton`, `PhotoCredit`

`/styleguide/` に全部品の見本を置く。`noindex` とする。CSP に合わせ、インラインの `style` 属性とスクリプトを使わない。

## 検証

| 項目 | 基準 |
|---|---|
| 色の組み合わせ | 文字は全背景で4.5:1以上。CIの単体テストで検査する |
| 操作部品の枠とフォーカス | 3:1以上 |
| 自動の検査 | `@axe-core/playwright` で重大な問題が0件 |
| 見た目の確認 | 幅320, 768, 1280px、ライトとダークの画面写真を残す |
| フォントの容量 | 合計110KB以下 |
| 性能 | `04_public_site.md` の目標を満たす |
| キーボード | マウスなしで検索から種ページまで操作できる |

### 操作の確認

次の5つを Playwright のテストにし、スマートフォンの幅でも通す。

1. 和名をひらがなで入れて種ページを開く
2. 古い学名から現在の学名へたどり着く
3. 県を選び、その県の種を見る
4. 種の出典の文献を開き、引用文をコピーする
5. 種ページから修正提案を開く

## オーナーの確認

G12 で、オーナーが staging の実物を見て判断する。色、文字、トップの印象を変えたい場合は `tokens.css` の変更で全サイトへ反映する。
